# Singly Linked List – Insertion Operations

Overview

Implemented a Singly Linked List in Java from scratch, focusing on fundamental insertion operations using Test-Driven Development (TDD).

Implemented Operations

append(int data) – Inserts a node at the end.

prepend(int data) – Inserts a node at the beginning.

insertAt(int index, int data) – Inserts a node at a specified index.


# Deletion Operations

deleteFirst() – Removes the first node.

deleteLast() – Removes the last node.

deleteAt(int index) – Removes a node at a specified index.

# Search Operations

contains(int data) – Checks whether a value exists in the linked list.

indexOf(int data) – Returns the index of the first occurrence of a value, or -1 if the value is not found.
